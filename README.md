# UrbanWear - E-Commerce Clothing Website

![UrbanWear](public/preview.webp)

A modern, fully responsive e-commerce clothing website built with React and Tailwind CSS, designed in Figma.

## 🌐 Live Demo
[https://urbanwear-theta.vercel.app](https://urbanwear-theta.vercel.app)

## 📸 Features

- 🏠 **Home Page** - Hero section, product collections, philosophy section
- 🛍️ **Shop Page** - Product grid with filter and sort functionality
- 👕 **Product Detail** - Size selector, color picker, quantity control
- 🛒 **Cart Page** - Cart items with quantity management and order summary
- 💳 **Checkout Page** - Complete checkout form with order summary
- 🔐 **Login/Signup** - Authentication pages with beautiful UI

## 🛠️ Built With

- **React.js** - Frontend framework
- **Tailwind CSS** - Styling
- **React Router DOM** - Navigation
- **Vite** - Build tool
- **Figma** - UI/UX Design

## 📱 Responsive Design

Fully responsive across all devices:
- Desktop (1440px+)
- Tablet (768px)
- Mobile (375px)

## 🚀 Getting Started

### Prerequisites
- Node.js v20+
- npm

### Installation

1. Clone the repository:
\```bash
git clone https://github.com/emperorx327/urbanwear.git
\```

2. Navigate to the project:
\```bash
cd urbanwear
\```

3. Install dependencies:
\```bash
npm install
\```

4. Start the development server:
\```bash
npm run dev
\```

5. Open your browser at:
\```
http://localhost:5173
\```
